# Invitación Noe Santiago 🦁

    pnpm install
    pnpm dev        # desarrollo
    pnpm build      # producción (carpeta dist)

- Datos, textos, fecha, mapa, WhatsApp, música y fotos: `src/config/invitation.js`
- Canción: `public/music/song.mp3`
- Fotos: `public/gallery/foto1.jpg` … `foto6.jpg`
- Cada sección es un componente en `src/components/`
- Vercel: Framework Vite, comando `pnpm build`, salida `dist`
